# Predicting Late Arrivals for Delta Air Lines at Salt Lake City

IS 4487 Final Project, Group 2: Drew Dillard, Tyler Dixson, Morgan Kearney, Alexander Roman

## Files

- `delta_flight_delays_final_project.ipynb`: the project notebook
- `delta_slc_flights_2025.csv`: every Delta flight into SLC in 2025 (from the Bureau of Transportation Statistics)
- `slc_weather_2025.csv`: daily weather at the SLC airport in 2025 (from NOAA)
- `data_prep.py`: the code we used to build the flight file from the raw BTS downloads
